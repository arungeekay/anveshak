# ANVESHAK (ಅನ್ವೇಷಕ) — AI Crime Intelligence & Investigation Platform

**KSP Datathon 2026 · Challenge 1: Intelligent Conversational AI for KSP Crime Database · Team Zen**

ANVESHAK is an AI investigation platform over the Karnataka State Police FIR
database. Officers query crime records in **Kannada or English, by voice or
text** — and every answer is grounded in verified SQL with visible case-ID
evidence. Beyond conversation, ANVESHAK works cases: a **serial-crime linkage
engine** fingerprints modus operandi across district boundaries, a **six-agent
investigation cell** assembles court-ready Investigation Packs with ranked,
evidence-cited leads, a **crime knowledge graph** answers multi-hop network
questions, and a nightly **Night Patrol** sweep raises proactive lead cards —
emerging hotspots, growing series, re-offending patterns — before anyone asks.
Role-based access mirrors the SHO/SP/SCRB hierarchy, every action is audit-logged,
and the entire system is deployed on **Zoho Catalyst** (QuickML, Data Store,
AppSail, Circuits, SmartBrowz, and more).

> 🚧 Build in progress — full documentation, architecture diagram, measured
> evaluation results (NL→SQL accuracy, linkage precision), setup instructions and
> demo credentials land here with the final submission.

**Data note:** all data in this repository is synthetic, generated by
`data_engine/` against the official FIR schema. Ground-truth crime series are
injected by configuration (`data_engine/planted/`) so that linkage and detection
accuracy can be measured and independently verified. No real case data, no real
persons. Protected attributes are never used as model features.
